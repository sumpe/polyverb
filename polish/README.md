# Trening polskich czasowników 🥟

A single-page Polish verb conjugation trainer for regular verbs.

- Quiz yourself on 10, 20 or 30 forms
- Conjugation classes: -ać, -ować, -ić / -yć (or all)
- Tenses and moods: present, past, compound future and conditional, with gendered past/conditional forms
- Conjugation tables for representative verbs (czytać, kupować, robić, uczyć)

## Usage

No build step: open `index.html` in a browser. Works offline (only the web font needs internet; it falls back to the system font).
